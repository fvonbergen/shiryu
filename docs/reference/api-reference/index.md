# API Reference

> **An API reference is a comprehensive, technical manual that serves as the definitive blueprint and source of truth for an Application Programming Interface (API).**
> Unlike high-level tutorials or conceptual guides that teach you how to build a project, the API reference acts as a technical contract. It provides an exhaustive, granular rundown of every single function, class, or endpoint available, detailing exactly how to format requests and what responses to expect.
